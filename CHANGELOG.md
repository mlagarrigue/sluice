### ⚠ BREAKING CHANGES

* **quic:** drop the two ACK delay fields never announced
* **postgres:** one way to write an array, AppendArray
* **postgres:** Array holds its values as a slice of T
* **quic:** a stream identifier is a StreamID
* **quic:** MaxIdleTimeout zero is refused, ADR 0018
* **quic:** the migration count moves into Stats
* **postgres:** Rows.Fields becomes NumFields
* **postgres:** MaxMessage becomes MaxMessageBytes (ADR 0018)
* **postgres:** TxConfig.Timeout becomes StatementTimeout
* **postgres:** IndexOutOfRange becomes IndexError
* **quic:** Config holds what never goes on the wire
* **join:** Merge becomes MergeJoin
* **quic:** bound ActiveConnIDLimit; bind a token's address
* **web:** answer a body's wrong label with 415
* **postgres:** bound the end of a COPY like a Tx

* **quic:** rotate keys per RFC 9001 §6 — a connection now follows a peer's
  key rotation and rotates its own keys before the AEAD limit instead of
  dying of its packet count; `Stats` gains a `KeyUpdates` field, so an
  unkeyed `quic.Stats{...}` literal no longer compiles.
* **web:** NewRouter panics on a bad table — `stream.NewRouter` returns
  `*Router` alone, no error: drop the `err` from `r, err := NewRouter(...)`;
  a pattern it cannot read, or a row an earlier row of the same method
  shadows, now panics at start-up, where the mistake is.
